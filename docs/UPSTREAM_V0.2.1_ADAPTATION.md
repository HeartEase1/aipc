## aipc 专项适配

### 调度和计费

- 选号使用渠道映射后的模型，账号白名单同时兼容已明确配置的公开别名。空白名单的 OAuth 账号仍不能凭借公开别名绕过平台模型支持检查。
- 渠道价格限制继续使用配置指定的请求模型或渠道映射模型，避免把已经映射过的名称再映射一遍。
- WebSocket 返回模型名和用量日志中的 RequestedModel 保留客户端原始名称，UpstreamModel 记录实际转发目标。
- Astra 内置价格仅作回退；现有目录价格、渠道和分组覆盖继续优先。ultrafast 使用 aipc 配置的 Fast 倍率和 priority 价格，不覆盖管理员定价。
- `none` 只作为推理映射来源，不增加上游整套按模型匹配规则配置。

### 会话失败释放

上游的无条件删除方式可能误删同一会话被其他请求复用的注册。本次改为请求级随机凭据和 Redis 原子比较：只有本请求新建且仍独占的注册才允许释放。并发复用、刷新或成功使用过的会话保留空闲超时语义。

跟踪在选号之前开始，覆盖等待并发、利润准入、转发失败和 `count_tokens` 失败。清理保留请求凭据，脱离取消信号执行，最长两秒。Redis 不可用时保持原有失败开放策略。

### 固定 Codex 模型清单

- 分组默认关闭，最多选择 10 个已绑定的 OpenAI 账号。获取时再次检查绑定关系、启停和过期状态。
- 按配置顺序合并模型，相同 slug 取先出现的定义，保留未知能力字段和显式 false。
- 保留 aipc 分组屏蔽模型规则；被屏蔽的模型不能通过固定清单重新出现。
- 没有可用账号时按配置返回错误或回退调度器。复制分组时清除固定账号配置。
- 能力补全采用实际路由及同步快照，实时上游明确声明优先，保留 false/null，不将桥接搜索能力无条件声明给原生路由。

### OAuth 缓存与模型能力同步

- OAuth 和 API Key 清单采用最多 512 项的缓存，新鲜期 60 秒，旧值可在 5 分钟窗口内用于后台刷新。刷新有独立 15 秒超时，不因单个客户端取消而中断共享获取。
- 缓存按账户、凭据和请求参数隔离，保留上游 ETag 并处理 304；401/403 淘汰对应缓存。保留 aipc 原有 OAuth 身份恢复、账户状态处理和故障转移。
- 账户同步返回模型能力与不完整警告，并保存到 `extra.upstream_model_metadata`。能力目录补充使用 models.dev，缓存 6 小时，不向目录服务发送账户凭据。
- 上游列表不可用时保留已有能力；404/405 可回退已配置模型。账户更换服务地址后，不再复用原地址的能力快照。普通编辑及批量 extra 更新不能覆盖服务端维护的同步快照。
- 合成清单按实际复合路由、渠道映射、账户映射查找上游模型，保留公开别名。能力取候选账户的交集，包含上下文、输出上限、输入模态、推理和工具支持；临时限流不会移除交集中的候选账户。候选查询失败时返回错误，避免错误放宽声明。
- API Key 清单每次按当前快照补全后计算最终 ETag；补全不修改共享缓存的原始清单。OAuth 原生清单保持透传。分组屏蔽模型及现有路由限制继续生效。

### Anthropic 推理管控与 Max 倍率

- Anthropic 分组支持 `low/medium/high/xhigh/max`，支持显式 `none` 来源映射；未指定 effort 时不主动开启推理。复合分组解析到 Anthropic 后同样生效，策略中的 `minimal` 目标按 `low` 处理。
- 延续 aipc 的一次映射后限制上限逻辑，支持 `output_config.effort`。不导入上游完整的按模型规则或超限拒绝模式。
- 跨协议请求根据实际模型支持的档位规范化，不能在策略执行后将 `xhigh` 再升成 `max`。原生 Messages、Responses 和 Chat 转发记录实际发出的 effort，降档后的请求按降档值计费。
- 仅 token 计费应用 Max 倍率。Fable 5.1 在 `max` 下默认 3 倍，其他模型默认 1 倍；公开别名使用实际转发模型识别默认值。`5.10` 不会误命中 `5.1`。
- 分组定价优先于渠道定价；生效规则中显式配置的正有限倍率优先于模型默认，`1` 表示不加价。按次、图片和视频计费不应用该倍率。
- Max 在既有长上下文、服务档、时间段和用户折扣计算链中只应用一次。账户自定义成本规则可以配置独立 Max 倍率；直接使用客户 `total_cost` 的账户统计不再重复乘。复合分组成本规则按实际平台匹配。
- 渠道、分组、账户成本配置及用户模型价格展示已接入新字段；远程价格目录仍需沿用现有审核激活流程。
- 利润控制保持 aipc 原有的账户倍率准入语义，并有回归验证。它不比较完整 token 售价与账户自定义成本，也不保证不同 Max 售价/成本倍率下的实际毛利；配置不同倍率时仍需核对成本规则。

### 图片 URL 转 base64

这是网关 Images API 的兼容功能，不是在线工作台专属功能。本次没有修改工作台页面。

部分第三方上游只返回 `data[].url`，但客户端需要 `data[].b64_json`。账号开启 `extra.images_url_to_b64_json` 后，网关下载图片并补齐该字段，仍保留 URL。

- 仅适用于 OpenAI API Key 账号的 Images 非流式响应；默认关闭。
- 已有 `b64_json` 或客户端明确指定 `response_format=url` 时不处理。
- 单项下载失败时保留该项原样，不将整个生成结果变成失败。
- 单图最多 20 MiB、下载最多 60 秒，只接受字节嗅探为 PNG/JPEG/WebP/GIF 的内容，data URL 也执行大小和格式检查。
- 拒绝回环、内网、链路本地地址以及解析结果中的非公网地址；每次连接固定已校验 IP，保留原 Host 和 TLS 证书主机名，防止 DNS 重绑定。
- 下载保留账号代理；经代理下载要求目标为 HTTPS，避免 HTTP 代理重新解析目标域名。无法安全下载时按原响应返回。
- 开启会增加下载延迟、服务器带宽及内存占用，base64 也会增大响应体。能直接使用 URL 的客户端通常无需开启。

### 价格文件热更新

只重建当前已选中的价格目录，不读取待审核远程候选。管理员激活和本地重载串行执行；解析使用同一份文件快照，重载前后校验内容指纹。格式错误、数字非法或文件在解析期间变化时保留原生效价格。删除 override 文件后移除其覆盖；当前生效的 bundled 文件缺失时保留原价格并报告错误。

### 运维和用量

代理归因保存错误发生时的 ID/名称，不从当前账号代理反推历史记录，不保存代理凭据。异步错误事件限制为最多 256 项、约 512 KiB，原始正文只保留限定窗口。

上游请求 ID 的响应头由管理员按账号配置，留空不采集。字段为空适用于历史记录、未配置账号和没有对应响应头的路径；不会把 WebSocket 响应对象 ID 冒充该字段。SQL 插入、查询和导出保留 aipc 折扣及会话相关列。
