## 同步内容

- 模型白名单允许任意位置的 `*` 通配符，并同步管理端输入校验与说明。
- Anthropic structured outputs beta 透传、禁用思考的桥接处理、GPT-5 及后续模型推理能力识别、工具参数和流式文本恢复。
- OpenAI Responses multi-agent beta 保留、上下文轮换后 WebSocket 链重置、模型不可用时探测结果归为未知、Alpha Search 只在成功完成响应后计费。
- OAuth 额度限制暂停到未来重置时间、无额度及退避状态自动恢复、调度缓存状态同步。
- Antigravity 空函数流故障转移、PDF inlineData、字符串 const 和纯签名片段处理；OpenCode Zen DeepSeek 推理占位兼容。
- OpenRouter Opus 5.5 价格别名、账户统计长上下文开关、图片价格回退、视频独立倍率展示，以及无定价的免费 Fast 零费用日志。
- 客户端断开记录为 499、界面定时器清理、额度倒计时、ccswitch 导入 URL、Windows 模型目录路径、Redis Compose 命令和初始化默认值修复。

## AIPC 适配与行为变化

1. 白名单冲突采用上游通配符实现，同时保留 `BlockedModels` 禁用优先和 `LegacyListOnly` 仅筛选列表语义。新增组合回归测试，覆盖中间通配符、禁用优先和旧配置兼容。
2. 核对账户统计及网关统一计费调用，保留 AIPC 请求时点定价、营销折扣、长上下文模型豁免和分组/账户开关语义。
3. 图片价格未配置时继承模型目录价格；显式输出价格为 `0` 时仍免费。管理员应核对原本留空的图片价格配置，不能继续把“未配置”视为“免费”。
4. 充值赠送、整单不返利、退款回收、海报生命周期与 multipart 上传修复、API Key 官方客户端限制、Pelican 自选模型及思考强度的实现未被本次上游修改覆盖。
5. 基线中的赠送流水展示修复继续保留：用户充值和并发变动记录使用独立赠送记录，显示实际到账、订单号和活动快照；赠送不计入付费充值总额。
