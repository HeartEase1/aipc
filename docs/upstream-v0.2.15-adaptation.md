# Sub2API v0.2.15 适配记录

合并基线：AIPC v1.0.89（`7b0d76392`，已同步官方 v0.2.13）。
目标：官方 v0.2.15（`f2669c8cf`），包含 v0.2.14 的增量。

## 主要更新

- EasyPay 回调签名复用防护；支付返回地址移除客户端自带查询参数，避免伪造成功回调。
- 初始化管理员凭据安全加固，以及 Go 1.27.2 和相关安全依赖更新。
- WebSocket 图片输入用量传递修复；长连接后续轮次刷新分组定价快照，使准入与计费采用同一轮定价。
- OAuth 搜索历史补齐 web_search 工具声明、Responses Lite additional_tools 适配，以及思考签名和协议转换修复。
- 平台目录和供应商协议配置统一，接入 Cline、Command Code；平台合法性由应用层统一校验。
- 多处前端异步竞态、定时器、弹窗和支付页面生命周期修复。
