# AIPC 对 Sub2API v0.2.11 的适配记录

日期：2026-09-30。官方来源：`Wei-Shaw/sub2api` `v0.2.11`（`96f4c115c9749078f90cbf210a01d39baf3f53b6`）。

## 已同步

- GPT-6.1 Sol：模型目录、Codex 元数据、各兼容入口、缓存与长上下文定价。
- Astra Ultrafast：能力识别和独立 6 倍模型倍率计费。
- Claude 原生限额重置兑换：管理端查询、二次确认、幂等兑换和审计接线。
- 余额模式在途额度预占：按请求估算成本在 Redis 原子预占，异步计费完成后释放；流式请求续期，进程异常由 TTL 回收。
- API Key 创建数量与频率限制：默认每用户最多 200 个有效 Key、每小时最多创建 60 次；删除不会返还创建次数。
- Claude Code 限制分组的 OpenAI 兼容入口改走降级分组。
- Codex 远程模型目录、最新 ChatGPT 套餐识别及 Use Key 配置调整。

## AIPC 适配边界

- 保留 AIPC 的版本号、充值赠送、官方客户端限制、Pelican 模型/思考强度、营销折扣、计费审计和既有路由扩展。
- 在途预占只影响余额模式；订阅模式、简易模式、无法定价（默认 fail-open）和 Redis 不可用时保持原有放行行为。
- 预占是准入保护，不是第二次扣款。结算仍走 AIPC 最终定价、营销折扣和固定费用规则，余额缓存扣减完成后才释放预占。
- 没有引入新的数据库迁移；AIPC 仍保留自己的版本文件，不改为官方 `0.2.11`。
