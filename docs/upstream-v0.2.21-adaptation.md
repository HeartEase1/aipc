# Sub2API v0.2.21 同步适配

同步范围：官方 `v0.2.18..v0.2.21`，包含 v0.2.19、v0.2.20 和 v0.2.21 的累计更新。AIPC 版本号暂保留 1.0.93，本次不创建发布标签。

## 合并内容

- 管理员 API Key 按操作、资源、IP 和有效期授权；管理 MCP OAuth（须显式配置 `MCP_PUBLIC_URL`，默认关闭）；注册邮箱黑名单。
- OpenAI/Composite 图片按张计费开关、图片尺寸分流、新模型目录与定价；OpenAI 缓存写入区分 30 分钟和 12 小时。
- 请求体内存预算、读写超时、流式及 WebSocket 转发、OAuth 刷新并发、图片链路和异步计费边界等官方修复。
- EasyPay 退款成功码配置、充值换算倍率最多六位小数、用量索引和页面加载优化。

## AIPC 适配

- 保留充值赠送、折扣、会员及邀请返利规则；充值页仍以服务端报价为准，不替换为官方页面的本地赠送计算。
- 用量日志的新增缓存字段与折扣快照共存，统一 SQL 列、参数、扫描顺序，并扩展折扣记录往返测试验证缓存字段。
- 保留地区访问限制、榜单及会员路由；管理设置页同时保留地区限制和新增权限密钥管理。
- API Key 认证快照版本升至 28，使已有 v27 缓存重新载入 AIPC 定价和上游新增隐私字段。
- Ent 与 Wire 从合并后的源定义重新生成；保留 AIPC 服务启动与清理逻辑。
- 保留 AIPC README、版本号和包含在线工作台的发布流程；同步发布工作流 Node.js 24。

## 运维及计费影响

- 官方新增的断连后读取上游时限，从客户端取消时开始，正常连接不会因此在 180 秒被截断。普通 HTTP 上游优先使用 `gateway.stream_data_interval_timeout`，无有效值时回退 180 秒；上游持续发送数据不会延长断连后的总时限。超出窗口才返回的 usage 仍可能无法收集。此处采用官方实现，不能把同步升级视为对账差异已解决。
- `gateway.request_body_read_timeout_seconds` 与 `gateway.downstream_write_timeout_seconds` 默认 120 秒，具体作用见官方配置注释；它们不是模型总响应时间设置。
- 缓存 12 小时写入定价与现有通用写入价格兼容；新增价格字段会影响对应请求的费用，升级后应核对上游价格卡。
- 增量迁移新增权限密钥、MCP OAuth、图片按张计费、缓存写入字段和用量索引。`249_add_usage_logs_api_key_cost_index_notx.sql` 使用并发建索引，首次升级可能耗时较长。
- 受限管理员密钥采用明确路由许可清单，AIPC 自有管理路由不会因普通权限自动开放；显式全权兼容模式沿用完整管理员能力。
